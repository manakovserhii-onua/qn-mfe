# qn-mfe: мережа масового обслуговування для мікрофронтендної і мікросервісної вебсистеми

Матеріали експерименту до статті N2 «Моделювання продуктивності мікрофронтендних і мікросервісних вебсистем на основі мереж масового обслуговування» (Манаков С. Ю., Трофименко О. Г., Лобода Ю. Г., Дика А. І., Ніколаєнко С. В.).

## Склад

| Шлях | Призначення |
|---|---|
| `config/system.json` | Єдиний опис системи (кейс «Електронний деканат»): станції, кількість каналів, середні часи обслуговування, водоспад сторінки для архітектур `mfe` і `mono`. Ним користуються стенд, генератор, модель та імітація |
| `config/system_B_scaled.json` | Варіант B: вузьке місце (`electives`) масштабовано до 2 екземплярів |
| `stand/` | Стенд на Node.js: кожна станція – окремий процес з FIFO-семафором на c каналів і експоненційним часом обслуговування; неблокувальний виклик наступної станції |
| `loadgen/loadgen.js` | Замкнене навантаження: N користувачів, час обдумування Z, затримка RTT на кожен HTTP-запит, fork-join завантаження сторінки |
| `model/qnmodel.py` | Аналітичні моделі: M1 – послідовне MVA; M2 – MVA + fork-join; M3 – M2 + поправка на сестринські запити (наближення Зайдмана для багатоканальних станцій) |
| `model/sim.py` | Дискретно-подійна імітація (SimPy) тієї ж мережі |
| `scripts/run_campaign.sh` | Вимірювальна кампанія (A і B; N = 10…140; 3 повтори; 10 с прогрів, 60 с вимірювання) |
| `scripts/run_mono.sh` | Перевірка прогнозу для монолітного SPA на стенді |
| `scripts/analyze.py` | Калібрування (закон використання за N = 10), прогнози, похибки MAPE |
| `scripts/whatif.py` | Аналіз «що буде, якщо»: моноліт проти мікрофронтендів, чутливість до RTT, межі пропускної здатності |
| `scripts/figures.py uk\|en` | Чорно-білі рисунки (PNG і TIFF 300 dpi) |
| `results/` | Сирі вимірювання, калібрування, прогнози, порівняння, рисунки |

## Відтворення

```bash
pip install simpy numpy scipy pandas matplotlib pillow
scripts/run_campaign.sh 10 60 3      # ~50 хв
scripts/run_mono.sh                  # ~10 хв
python3 scripts/analyze.py
python3 scripts/whatif.py
python3 scripts/figures.py uk
```

Середовище вимірювань: Linux, 2 vCPU, 8 ГБ ОЗП, Node.js 22, Python 3 + SimPy 4.1.

## Основні результати (MAPE, %)

| Конфігурація | Модель | X | R |
|---|---|---|---|
| A (базова) | M1 послідовне MVA | 6,21 | 48,78 |
| A | M2 MVA + fork-join | 1,33 | 8,65 |
| A | M3 запропонована | 1,21 | 6,99 |
| A | імітація | 1,12 | 4,56 |
| B (масштабоване вузьке місце) | M1 | 7,55 | 60,58 |
| B | M2 | 2,27 | 11,48 |
| B | M3 | 1,60 | 6,74 |
| B | імітація | 1,44 | 4,98 |
