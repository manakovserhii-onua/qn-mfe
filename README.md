# qn-mfe: метод аналізу середніх значень із клієнтським розгалуженням запитів для мікрофронтендної і мікросервісної вебсистеми

Матеріали експерименту до статті N2 «Метод аналізу середніх значень із клієнтським розгалуженням запитів для оцінювання продуктивності мікрофронтендних і мікросервісних вебсистем» (Манаков С. Ю., Трофименко О. Г., Лобода Ю. Г., Дика А. І., Ніколаєнко С. В.).

## Склад

| Шлях | Призначення |
|---|---|
| `config/system.json` | Єдиний опис системи (кейс «Електронний деканат»): станції, кількість каналів, середні часи обслуговування, водоспад сторінки для архітектур `mfe` і `mono`. Ним користуються стенд, генератор, реалізація методу та імітаційна модель |
| `config/system_B_scaled.json` | Варіант B: вузьке місце (`electives`) масштабовано до 2 екземплярів |
| `stand/` | Стенд на Node.js: кожна станція – окремий процес з FIFO-семафором на c каналів і експоненційним часом обслуговування; неблокувальний виклик наступної станції |
| `loadgen/loadgen.js` | Замкнене навантаження: N користувачів, час обдумування Z, затримка τ на кожен HTTP-запит, fork-join завантаження сторінки |
| `model/qnmodel.py` | Розв'язання аналітичної моделі (замкненої мережі МО з графом fork-join) трьома варіантами методу: M1 – класичний MVA; M2 – MVA з fork-join; M3 – запропонований метод, M2 + поправка на сестринські запити (наближення Зайдмана для багатоканальних станцій) |
| `model/sim.py` | Дискретно-подійна імітаційна модель (SimPy) тієї ж мережі |
| `scripts/run_campaign.sh` | Вимірювальна кампанія (A і B; N = 10…140; 3 повтори; 10 с прогрів, 60 с вимірювання) |
| `scripts/run_mono.sh` | Перевірка прогнозу для монолітного клієнта (SPA) на стенді |
| `scripts/analyze.py` | Калібрування (закон використання за N = 10), прогнози, похибки MAPE |
| `scripts/whatif.py` | Аналіз «що буде, якщо»: моноліт проти мікрофронтендів, чутливість до мережної затримки τ, межі пропускної здатності |
| `scripts/realized_demand.py` | Фактична потреба вузького місця в кожному прогоні та розрахунок методом M3 за потребами, виміряними в тих самих прогонах |
| `scripts/figures.py uk\|en` | Чорно-білі рисунки (PNG і TIFF 300 dpi) |
| `results/` | Сирі вимірювання, калібрування, прогнози, порівняння, рисунки |

## Відтворення

```bash
pip install simpy numpy scipy pandas matplotlib pillow
scripts/run_campaign.sh 10 60 3      # ~50 хв
scripts/run_mono.sh                  # ~10 хв
python3 scripts/analyze.py
python3 scripts/whatif.py
python3 scripts/realized_demand.py
python3 scripts/figures.py uk
```

Середовище вимірювань: Linux, 2 vCPU, 8 ГБ ОЗП, Node.js 22, Python 3 + SimPy 4.1.
